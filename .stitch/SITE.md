# DG Montador de Móveis — Site Specification & Roadmap

## 1. Project Overview
- **Project Name**: DG Montador Landing Page
- **Stitch Project ID**: `projects/11498287092425392021`
- **Vision**: Landing page de alta conversão para serviços de montagem e desmontagem profissional de móveis, com cotação rápida e atendimento via WhatsApp.

## 2. Core Value Proposition
- "Montagem bem-feita. Sua casa do seu jeito."
- Preços claros a partir de R$ 59, pontualidade, proteção ao piso e garantia de 90 dias.

## 3. Tech Stack & Delivery
- **Framework**: Tailwind CSS (CDN/Custom config) + HTML5 + Vanilla JS
- **Fonts**: Google Fonts (`Syne` e `Plus Jakarta Sans`)
- **Icons**: Material Symbols Outlined
- **Assets**: Imagens de mascote 3D transparentes locais em `assets/`

## 4. Sitemap
- [x] `index.html` — Landing page oficial com seções:
  - Hero (com Mascote 3D e CTA de orçamento)
  - Serviços (Filtros por categoria: Quartos, Salas, Cozinhas)
  - Manifesto & Qualidade (Padrão superior e cuidado com o piso)
  - Como Funciona (Fluxo transparente em 3 passos)
  - Valores (Tabela de preços inicial e diferenciais)
  - Formulário de Contato / Cotação Rápida WhatsApp
